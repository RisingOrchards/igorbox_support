# 3D Printable Enclosure

If you purchased the bare "DIY" PCB version of the LabRat, you can 3D print your own enclosure. We provide STL files for the enclosure that can be found on Thangs (url goes here).

:::tip
The enclosure is designed to be printed with a 0.4mm nozzle and 0.2mm layer height. The enclosure is designed to be printed without supports.
:::
