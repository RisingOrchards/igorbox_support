# Audit Log

The audit log is a running record of everything that changes in your Studio — useful for "who deployed that?" or "when did this controller get reconfigured?". Find it under **Settings → Audit Log** (Admins and Owners only).

## What it records

Just about every meaningful action, including:

- **Members** — invited, accepted, role changed, removed.
- **Controllers** — provisioned, configured, firmware updated, deleted.
- **Shows** — created, edited, deployed, deleted.
- **Media** — uploaded, renamed, deleted.
- **Triggers & Logic Rules** — created, edited, deployed, deleted.
- **Settings** — WiFi, IP allow-list, and billing changes.

## Reading it

Each entry shows **when** it happened, **who** did it, the **action**, what was **affected**, and whether it **succeeded**. The newest entries are at the top, and the most recent 100 load first.

Use the **search** box and the **action** / **type** filters to narrow things down — for example, every "deployed" action, or everything that touched a particular controller.
