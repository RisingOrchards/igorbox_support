# Keyboard Shortcuts

The timeline editor is built for fast keyboard-driven editing. The shortcuts here work when the editor (not a text input field) has focus.

## Transport

| Key | Action |
| --- | --- |
| `Space` | Play / Pause |
| `Home` | Jump to start of show |
| `End` | Jump to end of show |
| `Left arrow` | Seek back one frame |
| `Right arrow` | Seek forward one frame |
| `Shift + Left/Right` | Seek back/forward one second |

## Zoom

| Key | Action |
| --- | --- |
| `+` or `=` | Zoom in |
| `-` | Zoom out |
| `0` | Fit show to viewport |

On a trackpad, two-finger pinch also works. On touch devices, pinch-to-zoom works the way you'd expect.

## Selection and editing

| Key | Action |
| --- | --- |
| `Cmd/Ctrl + Z` | Undo |
| `Cmd/Ctrl + Shift + Z` | Redo |
| `Delete` / `Backspace` | Delete selected clips or control points |
| `Ctrl + click` | Add to selection (multi-select) |
| `Cmd/Ctrl + A` | Select all clips on the focused track |
| `Esc` | Cancel the current operation (drag, draw, etc.) |

## Tools

| Key | Action |
| --- | --- |
| `S` | Switch to Select tool |
| `D` | Switch to Draw tool |
| `X` | Switch to Split tool |
| `E` | Switch to Delete tool |

## Touch / mobile

The editor is fully usable on iPad and large phones in landscape:

- **Single-finger drag on a clip** — moves it
- **Single-finger drag on empty space** — pans the timeline
- **Two-finger pinch** — zooms
- **Tap a clip** — selects it
- **Long-press a clip** — opens the context menu

Most editing operations work with touch. Some interactions that rely on a modifier key (Alt+drag, Ctrl+click) don't have direct touch equivalents — use the toolbar buttons for those.
