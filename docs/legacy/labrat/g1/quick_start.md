# Overview

:::info Legacy product
The LabRat G1 is no longer in active production. These docs remain for existing customers — for the redesigned successor, see [LabRat G2](/docs/legacy/labrat/g2/overview).
:::

The LabRat is a simple 1 input and 1 output box that can trigger many types of animated props/decorations.
