# Discord Server

You can join our Discord server by going to [discord.igorbox.com](https://discord.igorbox.com)

## Channels

### News and Updates

In this category, we have our announcement channels that can be subscribed to other discord servers.

- **announcements** - This is our general announcements channel for things like events, new feature launches, new controllers, etc.
- **product-news** - This is where we announce things we have going on with new controllers and features.
- **firmware-releases** - This is where we announce the new firmware and changes that you may be interested in.
- **docs-updates** - When we update help.igorbox.com with meaningful changes, we announce it here.

### General Chat

This is where all users can connect, ask questions, and chat.

- **general** - The general chat for basically anything relevant.
- **build-help** - Need help with building something new and cool, this is your place.
- **showcase** - Brag a bit. Show off what you've built!

### IgorBox Users

This is a special group that requires a validated IgorBox account.

You need to link your discord to IgorBox and then ask Carl to `/verify_me`

Once complete, you'll have this group of channels available.

- **user-chat** - A place for IgorBox users to connect and help each other
- **user-support** - A more formal support forum for filing tickets and getting staff to help.
