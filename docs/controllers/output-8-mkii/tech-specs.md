# Tech Specs

The reference card for the install team.

:::danger
The figures here are working limits. If you choose to operate outside them, you do so at your own risk.
:::

## Power

|  |  |
| --- | --- |
| Supply voltage | 9–24V DC |
| Recommended supply | 12V or 24V, 1A minimum |
| Connector | 5.5 × 2.1 mm barrel jack, center-positive |

:::warning
Do not exceed 24V on the supply input. Higher voltages will damage internal components.
:::

## Outputs

### Multistate channels (1–6)

|  |  |
| --- | --- |
| Current rating | 1.5A continuous |
| Voltage range | Up to 24V DC |
| Modes | Mechanical relay or solid-state, software-selectable |

### Standard channels (7–8)

|  |  |
| --- | --- |
| Current rating | 3A continuous |
| Voltage range | Up to 24V DC |
| Type | Mechanical relay |

We don't support running mains AC voltage through any IgorBox channel.

## Inputs

|  |  |
| --- | --- |
| Channels | 2 |
| Type | Optically isolated, polarity-insensitive |
| Voltage range | 6–48V AC or DC |

## Audio

|  |  |
| --- | --- |
| Output | Stereo line level, 3.5 mm TRS jack |

For best results, feed the controller 44.1 kHz / 16-bit lossless audio (WAV or FLAC).

## Connectivity

|  |  |
| --- | --- |
| Ethernet | 100Base-T, RJ45 |
| WiFi | 2.4 GHz, 802.11 b/g/n |

## Storage

32 GB onboard, formatted for low-latency audio playback. Not user-serviceable. If you need more, [talk to us](/docs/contact).

## Mechanical

|  |  |
| --- | --- |
| Case material | 16ga Steel |
| Mounting | Wall or DIN rail (with optional DIN-rail kit). See [Mounting](/docs/controllers/shared/mounting) |
| Operating temp | 0–50 °C |
| Storage temp | -20–70 °C |
